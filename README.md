# Quran Data

Данные приложения QuranApp. Структура соответствует существующему репозиторию Quran-data.

```text
translations/<язык>/*.db
tafsirs/<язык>/*.db
word-translations/<язык>/*.json
transliterations/ayah/<язык>/
transliterations/word/<язык>/
scripts/
licenses/
ATTRIBUTION.md
manifest.json
```

В manifest 211 записей: 160 типа translation (включая прежний legacy-модуль),
31 тафсир и 20 пословных наборов. ID, пути и байты существующих баз сохранены.
В интерфейсе пословных переводов отображается один вариант на язык.

Все path относительные и указывают на файлы внутри этого репозитория.
Записей download_url/url нет: базы загружаются из соответствующих папок GitHub.
Привязки к modules-v2, localhost и рабочему столу нет.

Исходники Markdown и полный резервный архив остаются в отдельной рабочей папке.
В transliterations сохранены справочные исходники; их отдельное отображение в приложении пока не подключено.
Авторы и источники перечислены в ATTRIBUTION.md; оригинальные условия сохранены в licenses/.

## Проверка

Из корня репозитория (Python 3.10+):

```sh
python3 scripts/validate_manifest.py .
```

Проверяются пути, размеры, SHA-256, SQLite и полный индекс пословных JSON.
Проверка целостности не подтверждает разрешение на публикацию.

## Размещение

Добавить содержимое этой папки в существующий репозиторий, сохранив структуру.
Файлы данных разместить первыми, manifest.json обновлять после них.
Существующие ветки, теги и выпуск modules-v1 не удалять: старые клиенты могут обращаться к прежним адресам.
Никакие файлы этим инструментом на GitHub не отправляются.
